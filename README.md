# Hospital Appointment System

A web-based hospital/clinic appointment system developed as an Object-Oriented Programming course project.

## Features (planned)
- Hospital/clinic and branch management with working hours and departments
- Medical services with duration and price
- Doctor and staff management with availability slots
- Appointment booking with conflict checking and approval workflow
- Role-based access: Patient, Doctor, Admin

## Technologies
- C# / ASP.NET Core MVC (.NET 8)
- Entity Framework Core + SQLite

## How to Run
1. Install the .NET 8 SDK
2. Clone the repository
3. Run `dotnet run --project HospitalAppointmentSystem.Web`
